# ADR-001：零依赖核心 + 可选增强依赖

## 状态
已接受

## 决策
核心包（engine/sandbox/snapshot/scheduler/storage/runtime）只用标准库；
REST（fastapi）、压缩（zstandard/lz4）、S3（boto3）均为可选 extras。

## 理由
让「填写配置后即可运行」的门槛最低，演示零安装跑通；
生产场景再按需安装增强依赖。

## 影响
- `requirements-core.txt` 为空
- `pyproject.toml` 用 `optional-dependencies` 分组
